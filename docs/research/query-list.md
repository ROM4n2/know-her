# query 清单（SERP 取证用检索词设计）

- 任务：Task 4 · 需求验证子计划（docs/plans/implementation_plan.md）
- 产出依据：`docs/research/persona.md`（核心画像=查异常出血的年轻女性，18–35）、`docs/research/supply-map.md`（既有供给清单）、`docs/research/gap-criteria.md`（判据已冻结，本文件只被其「query 集」口径消费，不改判据）
- 消费方：SERP 取证（按 `gap-criteria.md` §② 逐 query 勾稽表执行）
- **事实红线**：本清单全部 query 为**从画像信息行为推演的设计词**，每行标注 `画像推演〔假设〕`；**禁止声称「用户真实搜索」**，任何行不得以真实搜索记录、搜索量、下拉词等未取证事实作依据。

## 验收标准（RED，先行写定，GREEN 后逐条勾稽）

1. **行数**：query 表数据行 **10–20 行**。
2. **意图覆盖**：意图类型三类（症状问诊 / 知识科普 / 求助支持）**各 ≥2 条**。
3. **敏感度混合**：高敏感与低敏感两类均出现，**不得全高、不得全低**。
4. **八列齐全**：每行恰含 8 列——# / query 原文 / 语言 / 意图类型 / 敏感度 / 检索渠道 / 设计理由 / 来源等级+置信度。
5. **渠道可无痕复现**：检索渠道限于可无痕复现的公开 SERP（百度 / 必应 / Google，或以 `site:` 限定的取证渠道，如 必应 site:xiaohongshu.com / 必应 site:zhihu.com）；知乎站内搜索、小红书站内搜索匿名不可复现〔限制〕〔实测（复核者 2026-09-22）〕，不得作为检索渠道。与画像「双主渠道=搜索引擎 + 教育/公益目录收录」矩阵一致（目录侧不作为 query 检索渠道，属于分发面，不在本清单内）。
6. **来源标注**：每行来源等级+置信度列标注 `画像推演〔假设〕` + 置信度（high/medium/low）；全表无「用户真实搜索」「搜索数据显示」类断言。
7. **设计理由一句话**：每行从画像的信息任务推演（如「判断是否需要就医」「求助而不暴露隐私」），不引用缺口判据阈值、不以「最大化缺口判定结果」为选词理由（防量身定制红线）。
8. **真人用词**：口语化、允许不严谨措辞，中英可混（对应画像「夹带英文/双语检索」假设）；不得整表行业黑话。

- **AC-2 意图覆盖**：症状问诊 5 条（#1–#5）、知识科普 5 条（#6–#10）、求助支持 5 条（#11–#15），三类各 ≥2 → 通过。
- **AC-3 敏感度混合**：高敏感 6 条（#3、#8、#11、#12、#13、#14）、低敏感 9 条（#1、#2、#4、#5、#6、#7、#9、#10、#15），非全高、非全低 → 通过。
- **AC-4 八列齐全**：表头 8 列，15 行数据全部填写 → 通过。
- **AC-5 渠道可无痕复现**：百度 5（#1、#4、#6、#9、#13）、必应 1（#2）、Google 3（#5、#10、#15）、必应 site:xiaohongshu.com 3（#3、#11、#12）、必应 site:zhihu.com 3（#7、#8、#14）；全部为可无痕复现的公开 SERP（其中 6 行原设计渠道为小红书/知乎站内搜索，匿名不可复现〔实测（复核者 2026-09-22）〕，已改为 `site:` 限定取证渠道并在渠道格内标注〔限制〕）；与画像「搜索引擎为双主渠道之一」一致；教育/公益目录侧属分发面，按口径不设 query → 通过。

## 去黑话化复核（REFACTOR，逐行过一遍用词）

复核口径：query 必须像真人会打的字——口语化、允许不严谨（错字、断句随意、语义含糊均可），但不得只有行业黑话。

- #1「又出了一点点血 正常吗」：口语，无术语 → 保留。
- #2「肚子不痛」而非「无伴随疼痛」：口语 → 保留。
- #3「有点害怕 要不要查」：情绪词 + 口语动词 → 保留。
- #4「拖尾」「一直不干净」：民间口语说法，刻意不用「经期延长」「阴道不规则流血」→ 保留（此行为去黑话化的锚点行）。
- #5 全小写、无标点的英文提问，像真人随手打的 → 保留。
- #6 两个「正常」重复，是真人打字的冗余，不修 → 保留。
- #7「是什么 好不好」：含糊问法（想问「要不要紧」却打成「好不好」），真人如此 → 保留。
- #8「有啥副作用」而非「不良反应」：口语 → 保留。
- #9「要注意啥」收尾，避免纯术语「筛查间隔」→ 保留。
- #10 英文术语行：`breakthrough bleeding` 是画像「夹带英文医学术语」假设的对应词，属必要术语而非黑话堆砌，且后接口语 `meaning` → 保留（全表仅此一处纯术语短语）。
- #11–#13 全口语（「不敢跟妈妈说」「怕尴尬」「不想让别人知道」）→ 保留。
- #14「一直不来」「要不要说」：口语 → 保留。
- #15「看病太贵」「哪里靠谱」：口语，中英混（对应双语/海外情境）→ 保留。
- 复核结论：全表术语密度可控——仅 #4、#9、#10 含医学词（拖尾/筛查/breakthrough bleeding），且均嵌在口语句中；无人名、无编造经历、无「用户真实搜索」类断言。REFACTOR 无需改动。
