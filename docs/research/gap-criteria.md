## ① 三要件定义（可机械判定）

> 对象单位：**候选条目** = 某 query 结果页上的一条结果（自然结果、精选摘要、问答块、视频/图片块中的条目均算），其指向一个可访问的内容页面。对候选条目逐件判定下列三要件，**三件全部满足**才称该条目为『合格供给』。
> **从严总则**：凡因页面无法访问、区域限制、登录墙等原因导致某要件的证据**不可得**，该要件一律按**不满足**计；不存在『存疑即通过』。

**要件 A · 来源可追溯（外链原始文献/指南一点即达）**

判定规则（逐项检查，机械二值）：
1. 该内容页面存在至少 1 条**指向站外**的引用链接，且该链接直接指向原始文献、临床实践指南、系统综述/共识文件或权威机构（如国际/国家级卫生机构、学会）的**原文页面**，而不是站内二次转述页、聚合页或搜索结果页。
2. 实际点击/请求该链接**可达**（HTTP 200 或等效正常呈现；404、域名无法解析、持续超时、被拦截均算不可达）。
3. 引用与正文断言的对应关系可识别（引用以脚注、编号、括注或紧随断言的链接形式出现，能指认某条内容依据哪条来源）。
- 满足：1 ∧ 2 ∧ 3 全部成立；否则不满足；证据不可得按不满足计。

**要件 B · 审核透明（审核人/日期/流程可见）**

判定规则（三要素齐备才算满足）：
1. **审核主体可识别**：页面或其固定入口（作者栏、编审名单、关于页）有具名署名——个人姓名，或具名机构/编审委员会（『××医院妇科团队』『××学会编辑委员会』算具名；『专业团队』『资深医生』『专家审核』等无署名文案**不算**，因可被任意仿冒）。
2. **日期可见**：发布日期、末次更新日期或末次医学复审日期至少其一明确标注。
3. **流程可核验**：存在可查的审核/编辑/纠错流程说明入口（页面链接或固定栏目），能核验内容经过何种审校环节。
- 满足：1 ∧ 2 ∧ 3 全部成立；否则不满足；证据不可得按不满足计。

**要件 C · 非营销导流（不以售卖/问诊导流为主目的）**

判定规则（出现下列任一即**不满足**）：
1. 页面主行动元素（首要按钮/横幅/弹层）是商品购买、付费课程/服务销售或促销。
2. 向自有或合作的**问诊、付费咨询、预约挂号**导流是页面主要模块（首屏主区域或正文收尾转化区）。
3. 正文以推销特定产品/服务为叙事终点（内容服务于转化）。
- 满足：上述三项均不出现，且页面以信息提供为主（导流元素仅处页脚/侧栏等次要位置或不存在）；证据不可得按不满足计。

## ② 缺口判据 + 三态裁决矩阵

### ②.1 口径定义（机械）

- **query 集**：Task 4 取证得到的 10~20 条真实中文检索词（『10~20 条』：默认阈值，冻结前可由用户调整）。本判据不预设具体用词。
- **结果页前两屏**：取证视口（桌面 1366×768，默认阈值，冻结前可由用户调整）下，从结果页顶部自然滚动至**第二屏底部**为止进入过视野的全部条目（自然结果 + 精选摘要/问答块/视频等一切 SERP 特性块中的条目）。取证须同时保存条目清单与截图，二者互为勾稽。
- **合格供给**：候选条目经 §① 三要件判定全部满足者。
- **可迁移填补渠道**：`supply-map.md` 表中某供给同时满足：(a) 三要件全满足；(b) 其版权模式明文允许非商业转载/翻译/链接复用（或有明确的非商业使用条款）；(c) 覆盖主题命中该 query 主题。三者齐备才算该 query 的可迁移填补渠道；任一不满足或无法核实则不算。
- **单 query 缺口成立**：对该 query，(i) 其结果页前两屏**无任何合格供给**，且 (ii) supply-map 中**无**该 query 的可迁移填补渠道。两条件须同时成立。
- **R（缺口率）** = 缺口成立的 query 条数 g ÷ query 总条数 N。为免浮点争议，比较一律用整数交叉相乘（见矩阵）。

### ②.2 裁决矩阵（三态，互斥完备）

| 态 | 判据（整数形式，N=总条数，g=缺口成立条数） | 含义与动作 |
|---|---|---|
| **GO** | 100·g ≥ 60·N | 缺口成立（覆盖多数目标检索情境），按计划建站 |
| **有条件 GO** | 30·N ≤ 100·g < 60·N | 缺口仅在部分主题/人群成立；**限定**到缺口成立的 query 对应主题/人群子集切入，建站范围收缩至该子集，且该子集须再单独复核 |
| **NO-GO** | 100·g < 30·N | 缺口不成立；转 **D1 退出路线**：不建站，改为向既有供给供稿/策展合作 |

- **阈值来源（先验理由，与既有证据无关）**：60% 表示『缺口须覆盖多数目标检索情境才值得以建站方式回应』（建站有持续维护成本，边际覆盖不足时供稿更优）；30% 表示『缺口低于三成时不再存在值得收缩切入的规模』。两者均为**默认阈值，冻结前可由用户调整**。
- **互斥完备性**：100·g 与 60·N、30·N 的比较是实数上的全序比较，`≥60·N`、`[30·N, 60·N)`、`<30·N` 三区间相邻且覆盖全体非负整数 100·g，边界等号归属已明示（=60·N 归 GO，=30·N 归有条件 GO）——任一取证结果恰落入一态。
- **逐 query 勾稽表（强制）**：取证时对每条 query 记录一行：query 原文 / 前两屏条目清单（含截图编号）/ 每条目 A·B·C 三件判定 / 可迁移填补渠道判定（含依据）/ 单 query 结论。汇总的 g、N、R 必须能从该表逐行复算，否则裁决无效。

### ②.3 空跑勾稽（虚构示例，仅测流程）

> **以下两条均为虚构示例，仅测流程**：query、站点、页面描述、判定结果全部虚构，不对应任何真实检索结果或真实站点；仅用于演示『三要件 → 单 query 结论 → 三态矩阵』可被机械执行。

**示例 1（虚构示例，仅测流程）**
- query（虚构）：「经期延长 咖啡色分泌物 怎么回事」
- 前两屏条目（虚构，共 5 条）：
  1. 某健康资讯聚合站文章——A：不满足（引用仅指向站内其他文章，无外链原始文献）；B：不满足（仅『专业团队』无署名文案，无日期）；C：满足（无导流）→ 不合格。
  2. 某问诊平台科普文——A：不满足（无引用链接）；B：不满足（有医生名但无审核/更新日期与流程入口）；C：不满足（正文收尾为『立即问诊』主按钮）→ 不合格。
  3. 某电商内容营销页——A：不满足；B：不满足；C：不满足（主行动为商品购买）→ 不合格。
  4. 某个人博客转载文——A：不满足（原始出处链接 404）；B：不满足（无署名无日期）；C：满足 → 不合格。
  5. 某论坛问答帖——A：不满足；B：不满足；C：满足 → 不合格。
- 可迁移填补渠道（虚构情境）：supply-map 中无覆盖该主题且三要件满足并许可复用的供给 → 无。
- 单 query 结论：(i) 无合格供给 ✓ 且 (ii) 无可迁移渠道 ✓ → **缺口成立**（g 计 1）。

**示例 2（虚构示例，仅测流程）**
- query（虚构）：「HPV 疫苗 接种后注意事项」
- 前两屏条目（虚构，共 4 条）：
  1. 某疾控机构科普页——A：满足（引用直达所依据免疫程序原文，链接实测可达，脚注对应正文）；B：满足（署名『××疾控免疫规划所』+ 更新日期 + 纠错/更新流程页链接）；C：满足（无导流）→ **合格供给**。
  2. 某疫苗预约平台页——C：不满足（主行动为预约挂号导流）→ 不合格（A/B 不再计）。
  3. 某门户健康频道转载文——B：不满足（无审核主体）→ 不合格。
  4. 某短视频条目——A：不满足 → 不合格。
- 单 query 结论：前两屏存在合格供给（条目 1）→ 条件 (i) 不成立 → **缺口不成立**（g 不计）。
- （条件 (ii) 在 (i) 不成立时不再影响结论，但取证表仍须照记，保证可复算。）

**矩阵空跑**：设 N=10，其中 6 条如示例 1、4 条如示例 2，则 g=6，100·g=600 ≥ 60·N=600 → **GO**（边界等号归 GO，与矩阵一致）。若 g=5：500 落入 [300,600) → **有条件 GO**；若 g=2：200 < 300 → **NO-GO（转 D1 供稿策展）**。判定路径全部为查表与整数比较，可机械执行。
