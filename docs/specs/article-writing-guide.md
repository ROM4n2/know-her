# know-her 词条写作规范

> 适用范围：`src/content/articles/` 下全部词条（含 `_template.mdx` 模板派生稿）。
> 规范源：ADR-0001 D4（审核人未就位⇒范围收缩）、D5（敏感内容边界结构化）、D6（多语言）。
> frontmatter 契约：`src/content.config.ts`（Zod `.strict()` + 3 条 superRefine 不变式），以 schema 为准，本文件不重复字段定义；字段级中文注释见 `src/content/articles/_template.mdx`。

---

## 1. 禁第二人称条件句（ADR-0001 D5③）

### 1.1 规则

正文**禁止**使用以「你 / 您」为主语的条件句给出行动指令，因为这在结构上等价于对单个读者做个体化医疗建议，而 `has_individual_advice` 恒为 `false`（Zod `z.literal(false)`），个体化建议不可判定化即不可发布。

禁用模式（出现即返修）：

- 「如果你有 X，就吃 / 停 / 去做 Y」
- 「你可能得了 X，应该去查 Y」
- 「你可以先自行观察 / 热敷 / 用药，如果没好转再……」

### 1.2 替代：一律第三人称枚举

把「对读者的条件指令」改写成「对人群的分组陈述」，枚举用「适用 / 不适用 / 需医生评估」三档，模板句式：

```markdown
- **适用情况 A 的人群**：〔人群特征与情形描述〕。
- **不适用情况 B 的人群**：〔禁忌 / 慎用情形描述〕。
- **需先由医生评估的人群 C**：〔孕期 / 哺乳期、合并症、证据不足等需个体评估的情形〕。
```

判据：改写后的每一句主语都是「人群 / 患者 / 医生」，不是「你」；句中不含「如果…就…」指向单个读者的分支。适用性结论统一落到「是否适用由医生判断」收口。

反例 → 正例：

| 反例（禁） | 正例（合规） |
| --- | --- |
| 如果你经期超过 7 天，就去吃避孕药调节 | 经期持续超过 7 天的人群：需由医生评估后再决定是否用药；适用与不适用由医生判断 |
| 你如果发烧超过 38.5℃ 吃退烧药 | 出现高热的人群：是否用药及用药选择由医生判断；同时对照 §3 红旗条目，命中即立即就医 |

## 2. 急症红旗清单格式（ADR-0001 D5①）

### 2.1 双写要求

红旗清单**必须同时**出现在两处，且一一对应（CI 校验，缺失拒绝合并）：

1. frontmatter `red_flags`（字符串数组，可为空数组但字段必填）；
2. 正文「急症红旗」区块（表格或列表，供渲染组件 `RedFlagCard` 使用）。

### 2.2 单条格式

```
「症状/体征 → 立即行动」；来源：〔机构〕《〔文件名·版本/年份〕》〔可核验 URL〕
```

要素缺一不可：

- **症状/体征**：可观察、可自判的描述（如「阴道大量出血伴头晕」），不写诊断名；
- **立即行动**：二选一，「立即就医」或「拨打 120」，不写「观察一下」类缓冲语；
- **来源**：机构 + 文件名 + 版本/年份 + URL，读者可回查原文条款。

### 2.3 急症指征来源说明

红旗条目只允许复用以下三类权威来源的急症指征，禁止自拟、禁止从科普二创转引：

- **WHO**：母体健康与急症处理相关指南/手册中的危险征象条目；
- **ACOG**（American College of Obstetricians and Gynecologists）：Committee Opinion / Practice Bulletin / Patient Education 中的 warning signs 与就医指征；
- **中华妇产科指南**：中华医学会妇产科学分会及《中华妇产科杂志》发布的指南、专家共识中的急症处理指征。

核验要求：

- 逐条回指原文条款（文件名 + 版本/年份 + URL），URL 经链检（lychee）可访问；
- 三方口径不一致时**并列列出**各自口径与来源，不自行裁定、不取平均；
- 暂时核验不到具体条款的指征：降级标注「待核验」并写入 `red_flags` 备注，`review_status` 保持 `draft` / `in_review`，不得以确定结论发布（对应 `reviewed_sensitivity` / `reviewed_medical` 如实填 `false`）。

## 3. 引用与摘要纪律（配合 §1/§2 使用）

- 来源摘要只转述 `source_url` 快照（`source_snapshot_date`）原文，逐句可回指；原文没有的数字、结论不补造——自查声明中的每个断言必须能指回正文证据行。
- 「来源主张」与「本站判断」分列成行，不混写；与权威指南口径冲突时并列双方口径。
- 译文词条填 `translation_of` 且 `lang` 不得为 `zh-CN`（superRefine 不变式②）；翻译不改写医学结论，只做语言转换，原文明示的歧义以译注形式标注。

## 4. 孟子式「以意逆志」的反面：高频坑注意事项

命名取孟子解诗之法的**反面**——孟子讲「以意逆志」「知人论世」，靠推测作者心意读诗；写医学科普恰恰相反：**不许以意逆志，只许按证据回指**。常见高频坑如下（每条都对应一个可机检或可人工复核的判据）：

| # | 高频坑 | 判据 / 处置 |
| --- | --- | --- |
| 1 | 第二人称条件句漏网（「如果…你就…」） | §1 反例表逐句过；命中即返修 |
| 2 | 红旗只写正文、漏写 `red_flags`（或反之） | 双写一一对应，CI 拒合并 |
| 3 | 编造来源：自拟文号、错记年份、URL 打不通 | 逐条回指原文条款 + lychee 链检 |
| 4 | 把「来源主张」写成「本站背书」 | 摘要区两行分列，冲突并列不裁定 |
| 5 | 医学审核未就位却把 `reviewed_medical` 填 `true` | D4：席位未齐一律 `false` + 正文降级横幅；填 `true` 必须同时给 `review_date`（不变式①） |
| 6 | frontmatter 自造字段（`title` / `tags` 等） | schema `.strict()` 直接 ZodError；标题写正文 H1 |
| 7 | 无个体化建议却在文末加「建议你…」收尾 | 结尾用第三人称枚举 + 「由医生判断」收口 |
| 8 | 译文忘填 `translation_of`、或填了却 `lang: zh-CN` | superRefine 不变式② 报错 |
| 9 | 追热点抢发，`review_status` 直接跳 `published` | 不变式③：published 要求 source/copyright/sensitivity 三段全 true |
| 10 | 二创转引当一手来源 | 只认 WHO/ACOG/中华妇产科指南等一手口径，转引须回到原文 |
