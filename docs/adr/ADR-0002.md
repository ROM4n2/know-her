# ADR-0002 · know-her 定位转型：从严肃医学知识库转向每日性科普与愉悦分享站

- 状态：Accepted
- 日期：2026-09-24
- 决策人：用户（主持 agent：`gemini-3.8-flash-high`）
- 输入：用户需求重定调（“科普性质分享站，每天分享避孕、愉悦等常识，免除繁琐医学专家审核”）+ vault-grill 双镜共识
- 关联决策：修订并覆盖 `ADR-0001` 中针对重型医学审核与严格自诊相关的设计（D1 策展路线正式落地，D4/D5 审核重担彻底解除）

---

## 1. Context（背景与动因）

在前期完成需求验证与工程脚手架后，实际运营面临核心现实矛盾：
1. **专家资源匮乏**：团队及开源社区无稳定执业医学专家常态化进行四段双人交叉审核；
2. **产品定位偏离**：原先面向“异常出血、恐慌自诊”的冷峻就医手册定位过重，阅读门槛高、合规包袱重；用户真实期待的是一个**更轻松、实用、每天能够汲取性健康常识（如何避孕、性爱技巧、愉悦提升、生理机制）的精选科普站**；
3. **内容供给逻辑重构**：网络上已有大量高质量第三方科普（果壳、谈性说爱、丁香、学术指南、性教育公益机构），无需从零撰写临床指南，只需做好**可信搬运与精选策展**。

---

## 2. Decision Drivers（双镜驱动因素）

- **用户体验与产品层**：
  - 降低读者认知负担：从“自查是否有病”转向“探索美好生活与自我关照”；
  - 零侵权风险下的广度覆盖：通过策展摘要直接对接全网最优质的长文，用户既能快速抓干货，又能一键跳转权威出处；
  - 内容丰富生动：涵盖避孕、愉悦、亲密关系、身体探索等多维度。
- **技术与工程实现层**：
  - **Schema 大幅瘦身**：彻底剥离复杂的四段医学审核状态机、强约束不变式；
  - **静态站基础设施完全复用**：已搭建的 Astro 5、Tailwind CSS、Pagefind 全文检索、RSS 订阅、GitHub Pages 部署体系 100% 继承，零浪费；
  - **双轨生产流转**：维护成本趋近于零，日常随手提一个 Markdown 文件即可发布。

## 3. Decision Outcome（核心决策事项）

### D8. 定位转型：生活化性健康与愉悦探索科普站
站点重新定位于：**一个现代、温暖、尊重的每日两性健康与性科普分享站**。聚焦四大主题分类：
- `contraception`（安全避孕与防病）
- `pleasure`（愉悦探索与性爱技巧）
- `body`（生理常识与身体认知）
- `intimacy`（亲密关系与心理沟通）

### D9. 内容形态双轨制（策展导读为主 + 开放全文为辅）
- **主流 A 轨（策展导读）**：针对全网保留版权的权威文章，提炼 3~5 个核心看点 + 精彩摘要 + 原作者与出处署名 + **一键直达原文外链**（100% 零侵权、零法律纠纷）；
- **开放 B 轨（全文收录）**：仅对明确持有 CC 协议、公有领域或获得原作者授权的高价值文献/手册，在站内提供完整图文收录。

### D10. Schema 减负与现代博客契约
重构 `src/content.config.ts`，定义简洁明了的现代 Content Collection：
- `title: z.string()`（标题）
- `pubDate: z.date()`（发布日期）
- `summary: z.string()`（一句话推荐/核心看点）
- `category: z.enum(['contraception', 'pleasure', 'body', 'intimacy'])`（分类）
- `tags: z.array(z.string()).default([])`（标签）
- `source_url: z.string().url()`（原文/出处链接）
- `source_name: z.string()`（出处机构或媒体，如“果壳”、“谈性说爱”、“WHO”）
- `author: z.string().optional()`（原作者）
- `is_full_text: z.boolean().default(false)`（是否为全文收录）
- **移除字段**：`reviewed_medical`、`review_status`、`has_individual_advice`、`review_interval_months` 及所有复杂的 superRefine 门禁代码。

### D11. 生产与更新双轨制
- **主通路**：日常手工极简录入，创建一个几行 frontmatter 的 Markdown 文件即可；
- **辅助通路**：保留未来基于 GitHub Actions 的定时候选抓取扩展位（收集为 Candidate Issues，人工挑选后一键发布）。

## 4. Consequences（影响与执行计划）

### 正面后果
1. **日常维护成本降至最低**：1 分钟即可录入一篇全网优质科普导读；
2. **零合规风险与零侵权负担**：不再背负“无专家审核即非法”的心理包袱，外链导读模式合法合规；
3. **架构轻盈健壮**：完全复用 Astro 5 静态性能、Pagefind 搜索、RSS 订阅，网站加载速度极快、部署零成本。

### 执行路线（落地改动清单）
1. 重构 `src/content.config.ts`：更新为 D10 轻量 Schema；
2. 改造页面与布局：
   - 首页 `index.astro`：支持分类 Tab 切换或分类徽章展示，优化卡片为现代精选流；
   - 详情页 `articles/[id].astro`：根据 `is_full_text` 动态切换，导读型文章高亮展示“核心干货”与“直达阅读原文”外链按钮；
   - 移除已废弃的重型医学审核警告组件；
3. 更新两篇试点示例为符合新定位的内容（如“避孕套常见误区精读”、“提升女性愉悦的几大要素”）；
4. 验证 `pnpm check` 与 `pnpm build` 100% 通过。
