## 核心看点速览

- **盆腔疼痛不等于妇科病**：疼痛可源于生殖器官，也可源于膀胱、肠道、盆底肌肉、神经，甚至与抑郁、焦虑、创伤史相关——就诊时医生需要跨系统排查；
- **慢性化的时间刻度**：疼痛持续**超过 6 个月**即被视为慢性疼痛，其评估路径与急性疼痛完全不同；
- **7 类需要紧急手术的情形**：阑尾炎或肠扭转、异位妊娠破裂、卵巢扭转（附件扭转）、卵巢囊肿破裂导致腹腔内大出血或盆腔脓肿、腹部或盆腔脓肿破裂、肠道撕裂或疝梗阻、腹主动脉瘤；
- **5 条必须立即就医的警示体征**：晕厥或突然失去意识、危险性低血压伴心跳加速（休克）、突然剧烈疼痛（尤其伴恶心、呕吐、大汗）、发热或寒战、绝经后阴道出血；
- **育龄期几乎必做妊娠试验**：所有盆腔疼痛的育龄期女性都要做，尿检阴性但怀疑早期妊娠时需血检（孕 5 周内血检更准确）；
- **慢性盆腔疼痛不推荐阿片类**：一线是治疗病因与非甾体抗炎药，必要时换用其他止痛药、SNRI 或加巴喷丁/普瑞巴林，并配合盆底物理治疗与认知行为治疗。

## 深度解读与临床要点

> 默沙东诊疗手册大众版指出：「盆腔疼痛可能是由这些器官中任何一个器官的问题引起的，或者是由肌肉骨骼、神经或心理健康状况引起的。」

### 一、疼痛的「形状」本身就是线索

医生会记录疼痛的多个维度：何时开始、有多严重、是锐痛、钝痛还是痉挛痛、突然出现还是逐渐进展、持续还是反复、与月经周期/进食/睡眠/性交/体力活动/排尿/排便是否相关、什么因素加重或缓解。这些描述往往比「有多疼」更有诊断价值：

| 疼痛模式 | 典型指向 |
| :--- | :--- |
| 周期性，与月经周期同步 | 痛经、子宫内膜异位症、子宫腺肌病、经间痛（排卵痛） |
| 突然起病、单侧、迅速达峰、伴恶心呕吐 | 卵巢扭转（附件扭转） |
| 突然起病、数小时内迅速减轻、常见于性交后 | 卵巢囊肿破裂 |
| 逐渐加重、伴发热与黄绿色恶臭分泌物 | 盆腔炎性疾病 |
| 与进食/排便相关，伴腹泻或便血 | 消化道疾病（IBS、IBD、憩室炎等） |
| 耻骨上方痛、尿频尿急尿痛 | 尿路感染或膀胱炎 |
| 慢性、有腹部手术或盆腔感染史、性交痛 | 粘连（瘢痕组织）或盆底肌筋膜疼痛 |

### 二、按系统拆解的病因全景

- **妇科**：痛经、子宫内膜异位症、子宫腺肌病、卵巢囊肿、盆腔炎、粘连、输卵管积水、子宫肌瘤（多数不痛，但压迫膀胱肠道或引起经量过多伴痉挛时会痛）、生殖道癌症；
- **消化系统**：胃肠炎、便秘、乳糜泻、憩室炎、肠易激综合征、炎症性肠病、腹部或腹股沟疝、结直肠癌；
- **泌尿系统**：尿路感染、已进入下尿路的肾结石、间质性膀胱炎（无感染的膀胱炎症）、膀胱癌；
- **肌肉骨骼与神经**：纤维肌痛、慢性肌筋膜痛、神经性疼痛；
- **血管**：腹主动脉瘤、盆腔淤血综合征；
- **心理健康**：抑郁、焦虑、躯体症状障碍、物质使用障碍——压力与抑郁会**加重任何类型的疼痛**，但本身很少单独造成盆腔疼痛；有过性创伤经历的女性或女孩可能出现慢性盆腔疼痛。

### 三、警示体征与「何时就医」的时间尺度

| 情形 | 建议就医时间 |
| :--- | :--- |
| 出现大多数警示体征（休克征象、突然剧烈疼痛、发热寒战） | **立即** |
| 绝经后阴道出血 | 同一天或数天内（不必当夜冲急诊，但也不宜拖成月） |
| 疼痛持续或稳定恶化 | 同一天或数天内 |
| 疼痛轻微且无警示体征 | 方便时就诊，延迟几天通常无害 |
| 轻度痛经 | 除非非常严重，一般不需要专门检查 |

### 四、检查为什么从「验孕」开始

所有盆腔疼痛的育龄期女孩和女性都要进行妊娠试验。这并非流程主义：异位妊娠破裂是能致命的急症，而早期妊娠在尿检上可能为阴性——怀孕小于 5 周时血液检测比尿液检测更准确。

其余检查按怀疑方向选择：全血细胞计数（CBC）、尿检或阴道/宫颈样本的性传播感染检测、盆腔超声、CT 或 MRI；若其他检查不能确定严重或持续性疼痛的病因，且怀疑严重原因（如异位妊娠破裂），可能需要进行腹腔镜或开腹探查。

### 五、治疗的层级：从病因到神经调控

1. **治疗病因本身**：感染用抗生素，囊肿/肌瘤/内异症病灶必要时手术；
2. **与月经周期相关的疼痛**：避孕药或其他激素避孕方法常被用于治疗痛经与子宫内膜异位症相关疼痛；
3. **止痛药阶梯**：首选非甾体抗炎药（NSAID，如布洛芬）；**一种 NSAID 无效可以换另一种**；NSAID 无效时可尝试其他止痛药；
4. **慢性疼痛的神经调控**：部分慢性盆腔疼痛患者可能使用 5-羟色胺-去甲肾上腺素再摄取抑制剂（SNRI）与加巴喷丁、普瑞巴林等神经止痛药物；
5. **不推荐阿片类**：默沙东明确指出，慢性盆腔疼痛**不推荐使用阿片类药物**，除非是活动性癌症患者或临终姑息治疗；
6. **非药物手段**：肌肉来源的疼痛可用休息、热疗与物理治疗；盆腔肌筋膜疼痛或与心理健康问题相关的疼痛，建议盆底物理治疗、性治疗或认知行为治疗。

### 六、绝经后女性的不同侧重

老年女性的常见病因结构不同：膀胱问题（含尿路感染）与便秘更常见，生殖道癌症（子宫内膜癌、卵巢癌、外阴癌）风险升高。绝经后雌激素下降会削弱阴道与尿道周围的骨骼、肌肉与组织，使膀胱感染更普遍；绝经期泌尿生殖系统综合征引起的性交疼痛，有时会被描述或感受为盆腔疼痛。

出现以下情况**必须就医**：阴道流血、体重与食欲突然减少、突然开始消化不良、感觉腹胀、排便突然改变。

## 常见认知误区破除

- **误区一：「盆腔痛就是妇科炎症，吃消炎药就行。」** 病因横跨六大系统，未明确诊断前的自我用药可能掩盖阑尾炎、异位妊娠等急症；
- **误区二：「疼得厉害才需要去医院。」** 突然剧烈疼痛伴恶心呕吐出汗正是需要立即就医的信号，而「越来越疼」同样重要；
- **误区三：「慢性盆腔痛只能长期吃止痛药。」** 指南推荐多学科路径：治疗病因 + NSAID + 神经调控药物 + 盆底物理治疗/性治疗/认知行为治疗，且**不推荐阿片类**；
- **误区四：「我没有性生活，不需要验孕。」** 育龄期盆腔疼痛的妊娠试验是标准流程，用以排除可能致命的异位妊娠。
