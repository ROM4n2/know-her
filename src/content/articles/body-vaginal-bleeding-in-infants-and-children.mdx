## 核心看点速览

- **先分辨来源**：出血可能来自阴道本身，也可能来自外阴、宫颈、子宫、输卵管或卵巢；有时看似阴道出血，但真实来源是**尿道或消化道**；
- **只有一种情况可能是生理性的**：婴儿在出生前经胎盘从母亲处吸收雌激素，出生后体内雌激素突然大幅减少，有时会在出生后 **1~2 周**出现少量阴道出血；
- **除此之外，儿童期任何阴道流血都是不正常的**，且并不常见——默沙东的明确结论是「儿童中的阴道流血是异常的、不常见的」；
- **常见病因谱**：阴道内异物（如厕纸、玩具）、损伤（包括可能的性虐待）、阴道感染（阴道炎）、外阴皮肤病（皮炎、硬化性苔藓）；尿道脱垂是不常见原因；
- **两种需要额外识别的信号**：性早熟（月经、乳房、阴毛腋毛提前出现，提示激素异常）与极罕见情况下的生殖道肿瘤；
- **就医原则非常明确**：阴道出血的婴儿和儿童**应立即就医**；
- **儿童保护是诊疗的一部分**：若怀疑性虐待，需由经过培训的医务人员检查与支持，并按当地对性侵犯受害者的医疗与法律要求进行记录。

## 深度解读与临床要点

> 默沙东诊疗手册大众版指出：「阴道出血的婴儿和儿童应立即就医。」

### 一、按年龄划分的病因谱

**婴儿期（唯一可能「正常」的阶段）**

出生前，胎儿通过胎盘从母亲体内吸收雌激素；出生后，体内大量雌激素突然大幅减少，有时会在出生后 1~2 周出现少量阴道流血。这一现象有明确的激素机制，通常仅需医师评估确认。

**儿童期（任何出血都属异常）**

| 病因 | 典型临床特征 |
| :--- | :--- |
| **阴道内异物**（如厕纸、玩具） | 通常有异味分泌物，并含少量血液；有时有异物放入史 |
| **损伤（包括可能的性虐待）** | 近期跌倒或其他可能的阴道区损伤原因；行走或坐立困难，生殖器、肛门或口腔周围有瘀伤或撕裂；阴道分泌物或发红 |
| **青春期早熟** | 在年少时即出现阴毛、腋毛与乳房发育 |
| **尿道内膜脱垂（突出）** | 少量阴道出血、厕纸上有血或排尿后出血；有时排尿时疼痛 |
| **皮炎（化学物质引起）** | 阴道或外阴出血，伴发红和/或肿胀，有时瘙痒或有分泌物 |
| **硬化性苔藓** | 外阴白色斑块，伴瘙痒 |
| **妇科癌症**（儿童中罕见） | 阴道口处可见肿块；持续腹痛或肿胀 |

需要特别注意：**化学刺激**既可引起皮炎，也可导致分泌物与瘙痒。可能接触到的化学物质包括洗衣剂、漂白剂、织物软化剂、泡泡浴、肥皂、女性卫生喷雾剂、冲洗剂、阴道乳膏、卫生巾、合成织物内衣、织物染料、厕纸、避孕套、隔膜与杀精剂。

### 二、警示体征：两类信息要同时看

1. **出血本身严重或持续**：意识丧失、虚弱、头晕目眩、皮肤冷汗、呼吸困难、脉搏微弱而快速（提示休克）；
2. **提示伤害或虐待的体征**：走路或坐着有困难，生殖器、肛门或口腔周围有瘀伤或撕裂，和/或阴道分泌物或发红。

出现以上任何一项，都应**立即**寻求医疗帮助，而不是先观察或自行处理。

### 三、就诊与检查：以儿童友好为前提

- **病史**：从父母（或看护人）与儿童（如果年龄允许）处获得；对婴儿需询问妊娠或分娩期间是否有并发症；**癌症家族史很重要**；
- **体格检查**：全身体检；如需盆腔检查，医生会先与家长和孩子讨论检查事宜，让他们知道会发生什么，并与孩子建立信任；检查目的应是获得必要信息，而不给儿童造成恐惧或不必要的不适；可能只做盆腔外检查（外阴与阴道口），如需盆腔内检查，通常会在**麻醉**下进行；
- **针对性检查**：
  - 出血严重且持续、怀疑盆腔感染 → 全血细胞计数；
  - 有阴道分泌物 → 用适合儿童的方法采集样本，检测常见阴道感染；
  - **怀疑性虐待** → 血液检查，并用尿液或阴道样本进行性传播感染检测；
  - 有性早熟迹象 → 激素检测；
  - 怀疑盆腔肿块或体格检查未发现出血原因 → 超声，不能确诊时进一步做 MRI。

### 四、治疗：四条并列的目标

默沙东把儿童阴道出血的处理目标列为四项，缺一不可：

1. **控制活动性出血**；
2. **治疗或管理潜在病因**，以防止未来发作；
3. **排除性虐待**；
4. **治疗铁缺乏症（贫血）**。

具体处置：感染需要药物治疗；从阴道中取出异物通常需要对儿童给予镇静剂或实施麻醉；非癌性或癌性肿瘤都需要手术治疗；若出血导致缺铁性贫血，应服用铁补充剂。

当怀疑存在性虐待时，应根据体格检查与**当地对性侵犯受害者的医疗和法律要求**进行记录；在评估期间和之后，儿童应接受**经过培训的医务人员**的检查与支持——这一条不是可选项，而是标准流程的一部分。

### 五、给照护者的三条实操建议

- **不要自行取异物**：阴道内异物的取出需要专业条件，自行操作可能造成损伤或把异物推得更深；
- **记录而不是下结论**：保留观察到的体征（出血时间、分泌物性状、外伤痕迹）与就诊信息，交给医生判断，避免自行归因；
- **留意性早熟的并行信号**：月经、乳房、阴毛与腋毛提前发育，加上激素异常，可能指向同一病因，需要激素检测与专科评估。

## 常见认知误区破除

- **误区一：「小女孩出血是『来月经早』，不用管。」** 儿童期任何阴道流血都不正常，默沙东的结论是「异常的、不常见的」，应立即就医；
- **误区二：「只有婴儿期的出血才是正常现象。」** 正确：仅出生后 1~2 周、由母体雌激素撤退引起的少量出血可能属于生理性，且仍需医师评估确认；
- **误区三：「没有外伤史就不会是损伤或虐待。」** 瘀伤、撕裂、分泌物异常、行走或坐立困难等体征本身就是需要加强关注的信号，应由专业人员评估；
- **误区四：「先在家观察几天再说。」** 对婴儿和儿童阴道出血，标准建议是立即就医；延迟可能延误异物、感染或肿瘤的处置。
